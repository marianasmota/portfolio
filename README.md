# Mariana Mota — Portfolio

Personal portfolio site, built with React + Vite and deployed to GitHub Pages.

Live at: https://marianasmota.github.io/portfolio/

## Development

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` automatically builds and deploys the site via GitHub Actions
(see `.github/workflows/deploy.yml`). No manual steps needed.

## Editing content

Site text (bio, skills, projects, contact links) lives in
[`src/data/content.js`](src/data/content.js) — edit that file to update the
content without touching any component code.
